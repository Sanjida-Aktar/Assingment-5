## 1️⃣ What is the difference between var, let, and const?
#### var
- scope: function scope
- variable declare with var are hosted and initialize with undefiend
- it can be updated and redeclare with in the same scope

#### let
- block scope
- it hosted but not initialized
- it can be updated but cannot be redeclare in the same scope

#### const
- block scope
- it hosted but not initialized
- it cannot be updated or redeclared
